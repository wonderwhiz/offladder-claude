# Tailor a CV to a job

Tailoring changes how someone describes their work, never what they did. Usually it means a new summary and five to ten rewritten lines, not a new CV.

## What you need

The job post (pasted text or the key parts) and their current CV. If either is missing, ask for it before writing anything.

## How to do it

1. **List the must-haves.** Skills, tools and experience the post marks as required or mentions more than once. Separate them from nice-to-haves.
2. **Map each must-have to the CV.** For each one, find the line that already shows it, often under a different name. Mark each as shown, shown weakly, or missing. Share this table with them first; it's the most useful part.
3. **Rewrite in the post's language.** Reword the lines that show a must-have using the employer's terms, and lead with results where they exist. Never add a tool, title, number or responsibility that isn't already in their CV or confirmed by them.
4. **Reorder.** Move the most relevant role bullets up. Cut what this employer won't care about.
5. **Rewrite the summary**: two or three lines naming the role, the strongest match and one result.
6. **Ask about the gaps**, don't fill them. For each missing must-have, ask whether they have done it anywhere (side project, volunteering, a previous role). If not, it stays missing; suggest how to address it in the cover letter or interview.
7. **Check the format for ATS**: one column, standard headings (Experience, Education, Skills), no text in images or tables, dates in a consistent format, file as .docx or text-based PDF.

## Output

1. The must-have table (shown, weak, missing).
2. The tailored summary and every changed line, each shown as before and after.
3. The gaps and one honest way to handle each.

## Rules

- If they couldn't talk about a changed line for a minute in an interview, put it back.
- Keep one long master CV and cut a tailored copy for each job.
- For a career change, translate old terms into the new field's words without changing what happened.
